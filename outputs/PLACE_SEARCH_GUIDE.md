# 서울 지역 검색·지도 선택

http://127.0.0.1:8000/search 에서 다음 순서로 이용하세요.

1. 출발지 선택을 누릅니다.
2. 강남역, 홍대, 서울숲 등 지역 이름을 입력하고 검색합니다.
3. 검색 결과를 클릭하면 지도 이동과 출발지 지정이 함께 적용됩니다.
4. 도착지 선택을 누른 후 다른 검색 결과를 선택하거나 지도에서 원하는 위치를 클릭합니다.
5. 길찾기를 누르면 해당 지역의 실제 OSM 도보 그래프를 가져와 서울시 혼잡도를 반영합니다.

직접 위도·경도 입력도 가능합니다. 같은 위치 두 개를 선택하면 길찾기는 비활성화됩니다. 서울 지원 범위 밖 지도 클릭은 안내 후 거절합니다.

## 현재 검색 범위

추가 키 없이 **서울시 공식 121개 관측지역의 이름 검색**을 제공합니다. 지역 검색 결과는 역 출입구나 건물 주소가 아니라 공식 Polygon 내부의 대표 위치이며, 화면에서 이 점을 명시합니다. 필요하면 지도에서 실제 출발 위치로 조정하세요.

모든 도보 위치를 지도 클릭으로 지정할 수 있지만, 모든 상호·주소를 이름으로 검색하려면 Kakao Local REST API 키가 필요합니다. 이 연결 코드도 구현되어 있습니다. 기존 서울시 API 키와 별개의 키입니다.

```dotenv
KAKAO_REST_API_KEY=카카오_REST_API_키
```

키 입력 후 서버를 재시작하면 상세 장소 검색이 활성화됩니다. 키워드 검색 결과가 없을 때 주소 검색을 시도합니다. [Kakao Local 공식 문서](https://developers.kakao.com/docs/ko/local/dev-guide)를 참고해 Local API 사용을 설정하세요. 키는 서버에서만 사용합니다. 카카오 성공 호출은 아직 사용자 키가 없어 모의 HTTP로 검증했습니다.

외부 무료 검색 서비스(Photon)는 실제 확인 시 403을 반환해 기본 검색으로 채택하지 않았습니다. 현재 앱은 해당 서비스에 요청하지 않습니다.

## 도보 범위 확대

현재 실행 프로젝트의 `.env`에서 `GRAPHML_PATH`를 비워 **여의도 고정 GraphML 사용을 해제**했습니다. `run_web.sh`도 저장된 여의도 그래프를 자동 선택하지 않습니다.

서울 및 인접 지역(위도 37.35~37.75, 경도 126.70~127.25)에서 출발·도착 좌표를 포함하는 지역 그래프를 동적으로 요청합니다. 과도한 다운로드를 막기 위해 그래프 반경 10km 상한은 유지합니다. 서울 전체를 한 번에 다운로드하지 않습니다.

처음 방문한 지역은 OSM 다운로드 때문에 오래 걸릴 수 있습니다. 같은 지역은 메모리 캐시와 OSMnx disk cache를 사용합니다. 혼잡도는 공식 121개 지역 안에서만 관측되므로 모든 도로에 실시간 혼잡 관측값이 있는 것은 아닙니다.

## 개발 및 테스트

새 endpoint: `GET /places/search?q=강남역`. 상세 검색 키가 없거나 외부 검색이 실패해도 공식 지역 검색과 지도 선택은 사용할 수 있습니다. 검색 결과는 캐시되며 사용자 검색 버튼으로만 요청합니다.

- TypeScript/Vite 빌드 성공
- Python 테스트 57개 통과
- 강남역~신논현역 인근 실제 OSM 경로: 약 827.5m, 서울시 데이터 source=seoul 확인
- 브라우저에서 강남역 이름 검색 → 출발지 적용 → 지도 클릭 도착지 지정 → 경로 요청 확인

실행: 프로젝트 루트에서 `./run_web.sh`. 개발 중 프론트는 `npm --prefix frontend run dev`로 실행할 수 있습니다.
