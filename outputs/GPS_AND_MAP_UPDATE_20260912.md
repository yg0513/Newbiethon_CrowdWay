# CrowdWay GPS / 혼잡 지도 수정

- 검색 화면에 `내 현재 위치를 출발지로` 버튼을 추가했습니다.
- 결과 화면에서 브라우저 Geolocation `watchPosition`을 이용해 현재 위치를 실시간으로 갱신합니다.
- 지도에는 현재 위치를 파란 점과 GPS 정확도 반경으로 표시합니다.
- 서울시 혼잡 스팟은 지도에 응답으로 받은 전체 관측 장소를 표시합니다.
- 왼쪽 텍스트 목록은 선택 경로에서 가까운 혼잡 장소 5곳만 정리합니다.
- 도로 구간별 빨강/노랑/초록 경로선은 제거했습니다.
- 선택 경로는 기존 느낌의 청록색 실선, 비교 경로는 회색 점선으로 복원했습니다.

## GPS 참고
브라우저 위치 권한이 필요합니다. 배포 환경에서는 HTTPS에서 사용하는 것을 권장합니다. localhost/127.0.0.1은 개발 테스트 용도로 브라우저에서 위치 기능을 허용하는 경우 사용할 수 있습니다.
