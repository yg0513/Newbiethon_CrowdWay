# CrowdWay 팀 피드백 반영본

이번 수정은 기존 구조를 유지하면서 화면 구성과 혼잡 시각화를 정리했다.

- 표지: 시작하기 버튼 아래 장식용 경로 그림 제거, 데이터 출처 안내 문장 제거
- 검색 화면: `좌표로 직접 지정` 체크박스/위도·경도 입력 UI 제거
- 로고: 모든 화면에서 CrowdWay 로고 클릭 시 홈으로 이동
- 결과 화면: 경로 정보(빠른 길/추천 길, 비교 정보)를 위쪽에 배치
- 결과 화면: 서울시 실시간 혼잡 데이터는 아래쪽 별도 섹션에 배치
- 경로 주변 혼잡: 선택 경로와 가까운 서울시 관측 장소를 최대 5곳 표시
- 인구 표시: 서울시 `AREA_PPLTN_MIN`/`AREA_PPLTN_MAX`를 받아 예상 인구 범위 표시
- 지도: 선택 경로의 실제 도로 edge별 혼잡도를 초록/노랑/빨강 실선으로 표시
- 지도: 서울시 관측 장소는 색 실선과 헷갈리지 않도록 점선 테두리 원형 스팟으로 표시
- 지도: 비교 경로는 회색 점선으로 표시
- 지도: 마우스 휠/트랙패드 및 터치 줌 활성화
- 백엔드: 경로 edge별 congestion + geometry를 segments 배열로 프론트에 전달
- 백엔드: 경로 주변 관측지역이 5곳보다 적으면 가장 가까운 공식 관측지역을 채워 최대 5곳 조회

## 실행

```powershell
python START_CROWDWAY.py
```

첫 실행 때 필요한 패키지 설치와 프론트 빌드를 자동으로 수행한다.
